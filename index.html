About ANT

ANT is a long-term project started in 2000 at the Physics Department of the University of Alicante, with the aim of computing electrical current in atomically defined nanostructures. It combines self-consistent field electronic structure calculations, typically density functional theory, with the Landauer transport formalism and the non-equilibrium Green’s function formalism.

ANT codes

Gaussian 09

ANT.Gaussian09

ANT.Gaussian09 is a computational tool for nanoelectronics that interfaces seamlessly with Gaussian 03/09. Applications include computing zero-bias conductance and electrical current under an applied bias voltage in molecular bridges and metallic atomic contacts, such as those created using scanning tunnelling microscopy or break-junction techniques.

Its use can also be extended to scanning tunnelling spectroscopy and the simulation of scanning tunnelling and electrostatic force microscopy.

Listed here as ANT.Gaussian09. The source repository is named ANT.Gaussian.

Gaussian 16

ANT.Gaussian16

ANT.Gaussian16 couples the ANT quantum transport code to Gaussian through the GauOpen Python interface. The ANT-Gau-Open workflow computes lead densities of states and the device transmission function using Gaussian electronic structure calculations and ANT’s electrode models.

The implementation includes optional OpenMP parallelisation in its Fortran component, controls for Gaussian processor and memory settings, and support for restarting calculations from Gaussian binary archive files.
