Atomistic NanoTransport

Technical Ant 1D


ANT.1D is completely written in FORTRAN90 and has been parallelized with MPI. It has been tested with the Intel compiler on various 32- and 64-bit platforms with and without MPI. It also been tested with the Portland group compiler, but only without MPI.

  • The interface with the CRYSTAL03 and CRYSTAL06 code is written in ANSI C++, and has been tested with the gnu C++ compiler on various 32- and 64-bit platforms.
