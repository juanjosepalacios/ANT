# ANT website

GitHub Pages website for ANT — Atomistic NanoTransport.

ANT.Gaussian09 links to the existing [ANT.Gaussian repository](https://github.com/juanjosepalacios/ANT.Gaussian).

The website is buildless. Edit `index.html` to update it. GitHub Pages publishes the root of the `main` branch.

## Documentation

The complete HTML documentation is in `doc/`, with its images, PDF references and stylesheet. Open `doc/index.html` locally, or follow the documentation links from `index.html`. Relative links work both in a checkout and on GitHub Pages.
